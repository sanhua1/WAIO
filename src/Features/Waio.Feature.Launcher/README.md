# 启动台(`launcher`)

**Ctrl+空格** 弹出搜索框:搜应用(中文名、拼音全拼、首字母,常用的排前面)、全盘文件和文件夹、网页,Tab 切换来源。
交互参考 MAIO 的启动器;文件索引的默认策略参考 Everything;文件名匹配质量和索引布局参考 oil-find。

## 命令

| 命令 | 默认快捷键 | 说明 |
|---|---|---|
| `launcher.show` | Ctrl+空格 | 打开 / 关闭(来源 = 全部) |
| `launcher.showApps` | — | 打开并进入"应用" |
| `launcher.showFiles` | — | 打开并进入"文件" |
| `launcher.rebuildIndex` | — | 重建文件索引 |

中文 Windows 上 Ctrl+空格 是"中文输入法开 / 关",被启动台占用后这个开关不能用(Shift 切换中英文不受影响)。

## 搜索

- 前缀:`a ` 只搜应用、`f ` 只搜文件、`d ` 只搜文件夹;`g`、`bd`、`bi`、`gh` + 空格直接网页搜索(可自定义)。
- 文件:空格分开的词都要出现在名称里;含 `\`(`/` 也行)或 `:` 的词按完整路径匹配(`documents\ report`、`d:\downloads\`);双引号括起来算一个词。
- Ctrl+⏎ 打开所在位置,Ctrl+C 复制路径,Ctrl+1–9 打开第几项;文件可以直接拖到别的程序里。

## 文件索引

直接读 NTFS 的主文件表($MFT)建索引,之后通过 USN 日志实时更新,索引存盘,下次启动直接读回。
默认索引所有固定的 NTFS 磁盘,不索引可移动磁盘;只支持 NTFS,需要管理员权限。

## 设置与数据

设置页「启动台」:面板大小、"全部"里显示多少条、网页搜索引擎、文件搜索开关与排除项等。
数据:`%LOCALAPPDATA%\WAIO\data\launcher\`(常用度 `usage.json`、索引 `index\<卷序列号>.bin`)。

## 所需能力

无特殊能力(打开程序走 `ILauncher`,默认以普通权限启动)。
